# Infrastructure Virtualisation Lab

Projet de laboratoire visant à simuler une infrastructure d'entreprise basée sur la virtualisation et la sauvegarde des machines virtuelles.

## Technologies utilisées

- VMware ESXi 8
- Veeam Backup & Replication
- Machines virtuelles Linux / Windows

## Objectifs

- Déployer un hyperviseur bare-metal
- Héberger plusieurs machines virtuelles
- Mettre en place une stratégie de sauvegarde
- Tester la restauration des machines virtuelles
